# Apply to `jumiknows/portfolio`

This project is intended as a replacement UI for the existing Vite/React portfolio.

1. Create a review branch.
2. Copy `src/`, `index.html`, `package.json`, `tsconfig.json`, and `vite.config.ts` into the portfolio repo.
3. Copy `public/resume.pdf` or replace it with the latest resume.
4. Run `npm install` and `npm run build`.
5. Preview desktop and mobile before merging.

The site intentionally keeps the GitHub Pages-compatible `base: './'` Vite setting.
